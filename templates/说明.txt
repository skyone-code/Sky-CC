Mac控制台 2.6.1 · 安装说明（SwiftUI 原生 · 菜单栏常驻版）
==============================================

这是一个原生的 macOS 桌面应用：自己的窗口、菜单栏常驻图标、原生界面，
不经过浏览器。散热/灯效等硬件控制由随包的后台服务负责
（Swift 直调 IOKit，XPC 通信，无需 Python、也没有网页界面）。

一、安装 app（一步）
    1. 打开这个磁盘映像
    2. 把「Mac控制台.app」拖到 Applications

二、安装散热内核扩展（一次性；装过可跳过）
    首次运行 app 时会自动检测：
      · 已安装  → 直接进入，全部功能可用
      · 未安装  → 弹出系统密码框，输入密码后自动装好
    也可以手动装：双击随附的「安装散热控制.command」，
    看到「✓ TongfangFanDriver 已在内核中运行」即成功。
    安装日志：/tmp/macconsole-kext-install.log

三、运行（菜单栏常驻）
    双击 Mac控制台.app：窗口直接打开，同时菜单栏（屏幕顶部）出现
    风扇图标，显示 CPU 温度。六个页面——
      仪表盘：设备 / 系统 / 序列号一屏总览
      监控：温度 / 风扇转速 / 电池 / 功耗 / 磁盘 / 网络 / 进程（1 秒刷新，电池 5 秒）
      全部信息：原生采集到的每一个字段（可搜索、可复制原始 JSON）
      控制：散热模式 / 风扇曲线 / 手动档位 / 性能模式 / 充电阈值 /
            海岸灯 / 屏幕亮度 / 音量 / 防休眠
      键盘灯效：单色 / 12 种动态灯效 / 6 分区配色 / 白平衡 / 记忆恢复
      系统：版本 / 外观 / 通用（开机自启）/ 菜单栏图标 / 后台服务状态
    关掉窗口后 app 不退，硬件服务照常工作；
    点菜单栏图标 →「打开控制台」随时把窗口叫回来。
    菜单栏面板里还能快速调亮度、切换散热模式、看实时温度。
    退出：菜单栏图标 →「退出控制台」（后台服务仍会继续守着散热与风扇曲线）。

四、屏幕亮度（重要）
    控制台亮度滑条和系统亮度滑条（F1/F2、控制中心）现在是同一个值：
    两边谁调都生效，面板背光平滑跟随。控制台关掉后系统滑条照常可用
    （面板 PWM 模式由登录项 pwmwake 守护保持，重启后仍在）。

五、键盘灯效记忆
    单色 / 灯效 / 分区 / 白平衡标定都会自动记忆；重启、多次开关 app、
    断电恢复后都按记忆值运行（登录项 rgbrestore 负责开机恢复）。

六、开机启动（可选，app 内设置）
    app 内设置：打开控制台 →「系统」页 →「通用」卡片 →
    「开机自动启动」开关。打开后登录时自动启动 Mac控制台
    （菜单栏常驻 + 硬件后台服务）。
    该开关与系统设置 → 通用 → 登录项 中的「Mac控制台」是同一份数据。
    （2026-10-17 起从旧版独立的「开机启动」小 app 迁到 app 内；
     若用过旧版，开启本开关时会自动清理旧的登录项，不会双重启动。）
    后台服务（MacConsoleHelper）由系统注册为登录项，随登录自动运行，
    不需要单独开关。

七、卸载
    双击随附的「卸载Mac控制台.command」，一并清掉 app、后台服务、kext、守护。

技术备注
  · 界面：SwiftUI 原生（macOS 14+）；硬件访问：TongfangFan.kext（EC）、
    USB HID（键盘灯）、SMC（传感器）、DPCD（屏幕背光）——全部 IOKit 直调
  · 架构：2026-10-22 v2.6.1 起为「UI + 后台服务」两个进程——
    界面（Mac控制台）只管显示，硬件读写全部由 MacConsoleHelper 负责，
    两者通过 XPC 通信；界面退出/崩溃都不影响散热与风扇曲线。
    已无 Python 依赖、无本地网页、无 8787 端口
  · 命令行助手 mcutil（随包在 Contents/MacOS/）：亮度 / 键盘灯 / 风扇 /
    `xpc ping` 查后台服务
  · 亮度：系统亮度注册表是唯一真相源，pwmwake 守护保持面板 PWM 模式；
    屏幕休眠时 DPCD 不可用，自动降级为只改系统亮度，唤醒即恢复
  · 日志：~/Library/Logs/MacConsole.log（app）、/tmp/macconsole-swift.log（排错）、
    /tmp/auxbright-console.log（亮度守护）
