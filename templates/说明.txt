Mac控制台 3.0 · 安装说明（LAPQC71 专版 · SwiftUI 原生 · 菜单栏常驻）
==============================================

这是一个原生的 macOS 桌面应用：自己的窗口、菜单栏常驻图标、原生界面，
不经过浏览器。散热/灯效/海岸灯等硬件控制由随包的后台服务负责
（Swift 直调 IOKit，XPC 通信，无需 Python、也没有网页界面）。

一、安装 app（一步）
    1. 打开这个磁盘映像
    2. 把「Mac控制台.app」拖到 Applications
    就这些。kext 和卸载器都不再单独放在磁盘映像里。

二、装散热内核扩展（一次性；装过可跳过）
    TongfangFan.kext **已经打包在 app 内部**，不需要在这里找文件。
      · 打开 app：已装 → 全部功能可用
      · 没装 → 页面顶部会出现一条提示，点「立即安装」，
               输入一次管理员密码，装好自动生效（无需重启 app）
    需要 kext 的卡片在没装时会整块灰着并写明原因，装好后自动恢复可用。
    安装日志：/tmp/macconsole-kext-install.log

三、运行（菜单栏常驻）
    双击 Mac控制台.app：窗口直接打开，同时菜单栏（屏幕顶部）出现
    风扇图标，显示 CPU 温度。页面：
      仪表盘：设备 / 系统 / 序列号一屏总览
      监控：温度 / 风扇转速 / 电池 / 功耗 / 磁盘 / 网络 / 进程
      全部信息：原生采集到的每一个字段（可搜索、可复制原始 JSON）
      控制：散热模式 / 系统功耗设置 / 系统调整 / 充电阈值
      灯效：键盘灯效 / 逐键投影 / 海岸灯 / 记忆恢复
      实验性：风扇手动档位 / 温控曲线 / ESC 功能键锁定 / EC 寄存器探针
      系统：版本 / 外观 / 菜单栏图标 / 后台服务状态
    关掉窗口后 app 不退，硬件服务照常工作；
    点菜单栏图标 →「打开控制台」随时把窗口叫回来。
    退出：菜单栏图标 →「退出控制台」（后台服务仍会继续守着散热与风扇曲线）。

四、关于登录项（现在很干净）
    正常情况下，「系统设置 → 通用 → 登录项」里只会有：
      · Mac控制台（后台服务 MacConsoleHelper，系统注册，随登录自动运行）
    键盘灯效恢复、面板模式保持这些后台动作都由 helper 自己完成，
    不再单独注册 bash 登录项。

五、软件记忆
    散热档 / 功耗档 / 充电阈值 / 灯效 / 海岸灯 / 各开关都会记住上次的选择。
    重启或 EC 断电后，helper 启动时会把它们重新写回硬件。
    （散热模式与系统功耗设置这两张卡片例外：它们以 EC 的真实状态为准，
      不做记忆覆盖 —— 原厂就是这么设计的，动功耗档时散热档会跟着走。）

六、屏幕亮度
    不在本 app 内调节，请用 macOS 自带的 F1/F2 或控制中心。
    面板的 PWM 模式由后台服务保持（DPCD 0x721），不占用登录项。

七、卸载（彻底）
    双击随附的「卸载Mac控制台.command」。
    它会清掉：主程序 / 后台守护 / 内核扩展及其开机项 / 两条登录项注册 /
    软件记忆 / 偏好设置 / 缓存 / 日志，最后自动扫一遍残留并报告。
    需要一次管理员密码（卸载 kext 用）。

  说明.txt                 本文件

技术备注
  · 界面：SwiftUI 原生（macOS 14+）；硬件访问：TongfangFan.kext（EC）、
    USB HID（键盘灯）、SMC（传感器）、DPCD（面板模式）——全部 IOKit 直调
  · 架构：UI + 后台服务两个进程——
    界面（Mac控制台）只管显示，EC/SMC/HID 读写全部由 MacConsoleHelper 负责，
    两者通过 XPC 通信；界面退出/崩溃都不影响散热与风扇曲线
    已无 Python 依赖、无本地网页、无 8787 端口
  · 命令行助手 mcutil（随包在 Contents/MacOS/）：`xpc ping` / `xpc get <path>` /
    `xpc post <path> <json>` 查后台服务，`sensors` / `rgb` / `fan` 排障
  · 日志：~/Library/Logs/macconsole-helper.log（后台服务）、
    /tmp/macconsole-swift.log（界面排错）、
    /tmp/macconsole-kext-install.log（kext 安装）
